# My Portfolio Website

## Lab Title
**Web Development Assignment – Responsive Portfolio Website**

## Description
This project is a **one-page responsive portfolio website** built using **HTML and CSS**. It showcases my personal information, skills, and projects. The design incorporates modern web development techniques including:

- **Flexbox** for layout alignment and spacing (header, hero section)
- **CSS Grid** for arranging skills and project cards
- **Responsive design** using media queries for mobile, tablet, and desktop devices
- **Relative units** (`rem`, `em`, `%`, `vw`, `vh`) for scalable spacing and typography
- **Hover effects and transitions** on buttons, links, and project cards
- **Keyframe animation** on “Full Stack Developer” text for a color-changing effect
- **CSS transforms** for interactive hover effects

The website is structured into clear sections: **Header, Hero, About, Skills, Projects, Contact, and Footer**.

---

## Features
- **Header & Navigation:** Logo and links using Flexbox; smooth scrolling to sections  
- **Hero Section:** Introduction with profile image; responsive stacking on smaller screens  
- **About Section:** Personal info with image and description  
- **Skills Section:** Skills displayed in a table/grid  
- **Projects Section:** Project cards centered with buttons linking to each project  
- **Contact Form:** Name, email, and message fields with a submit button  
- **Footer:** Back-to-top link for easy navigation  
- **Animations:** Hover effects on interactive elements; color-changing keyframe animation  

---

## Responsive Behavior
The website has been tested for different screen sizes:

- **Mobile (portrait)**: 320–375px wide, 568–667px tall. Hero text stacks above image; projects and skills stack in a single column.  
- **Mobile (landscape)**: 667px wide, 375px tall. Layout adapts; buttons remain visible; no horizontal scroll.  
- **Tablet (portrait)**: 768px wide, 1024px tall. Hero section shows text and image side by side; 2-column grids for projects and skills.  
- **Tablet (landscape)**: 1024px wide, 768px tall. Layout adjusts; text remains readable.  
- **Desktop/Laptop**: 1024–1440px wide, 900–1200px tall. Full layout with multiple columns for projects and skills; hover effects active.  
- **Ultra-wide screens**: 1600px+ wide. Content remains centered with consistent spacing; footer stays at the bottom.
