# Wanderlust Travels - Travel Agency Website

## Project Theme
**Travel Agency Website** – A fully responsive, visually appealing static site showcasing travel tours, itineraries, testimonials, and a contact form.

## Project Overview
This project demonstrates a professional travel agency website built using **HTML5 and CSS3**. It incorporates **semantic structure**, **responsive design**, and modern **visual styling** using Flexbox and Grid. The website provides a real-world interface suitable for a travel agency looking to showcase their services.

## Features Implemented
- **Hero Section:** Eye-catching banner with heading, tagline, and call-to-action button.
- **Tour Packages:** Grid of tour cards showing images, destination details, duration, and pricing.
- **Testimonials:** Traveler feedback displayed in responsive cards.
- **Sample Itineraries:** Organized list of sample travel itineraries.
- **Contact Form:** Accessible form for inquiries with proper labels and required fields.
- **Navigation & Header:** Logo, internal navigation links, and **skip-to-content link** for accessibility.
- **Footer:** Social icons, contact links, and copyright notice.
- **Responsive Layout:** Fully adjusts to desktop, tablet, and mobile screens.
- **Visual Enhancements:** Hover effects, transitions, section spacing, consistent color palette, and modern typography.
- **Accessibility:** Images with meaningful `alt` attributes, labeled form fields, and focusable skip link.

## Breakpoints & Layout Techniques
- **Desktop (≥1024px):** Multi-column grids for tours and testimonials.
- **Tablet (768px–1023px):** Grid stacks or two-column layout for readability.
- **Mobile (≤480px):** Single-column stacked layout; responsive hero and buttons.

**Techniques Used:**
- **CSS Grid:** For tour cards, testimonial cards, and itinerary lists.
- **Flexbox:** For header, footer, and button alignment.
- **CSS Variables:** For colors, spacing, and typography.
- **Media Queries:** For responsive design across devices.
- **Animations:** Keyframe fade-in effect for hero content.
- **Hover Effects:** Interactive hover transitions on buttons and cards.
